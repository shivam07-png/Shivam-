## Overview
This project analyzes sales transactions to identify revenue trends, product/category performance, regional differences, and (where available) profitability.

## Dataset
The notebook attempts to load a public sample Superstore CSV from:
https://raw.githubusercontent.com/plotly/datasets/master/superstore.csv

If unavailable, download a compatible Superstore CSV and save it beside the notebook as `Sample - Superstore.csv`. The dataset should include a `Sales` or `Revenue` field. Date, category, region, segment, profit, quantity, and product fields enable additional analyses.

## Technologies
Python, Jupyter Notebook, pandas, NumPy, Matplotlib.

## Setup and run
1. Install Python 3.10 or later.
2. Open a terminal in this project folder.
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Start Jupyter:
   ```bash
   jupyter notebook
   ```
5. Open `Shivam_Kumar_SalesDataAnalysis.ipynb` and run all cells from top to bottom.
6. Review the generated charts and tables, then complete the report with actual findings.
